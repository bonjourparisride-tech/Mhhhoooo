Bonjour Paris Chauffeur — Vercel deployment package

This is the complete one-file website. The HTML includes the site code, styles,
fonts, and photos; no separate assets or backend are required for the site itself.

Deploy with Vercel:
1. Upload/import this folder as a Vercel project, or unzip it and run `npx vercel --prod` from this folder.
2. Vercel uses the included vercel.json and package.json to publish dist/index.html.

Booking contact actions still use the configured email/WhatsApp integrations.
